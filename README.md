# Pterodactyl/Pelican egg for Axolotl-PM

This repository contains an egg for Pterodactyl/Pelican which can be used to install Axolotl-PM in their instance.

## Usage
Go to your panel's Egg management tab, and click `import` button. Then, upload [egg-axolotl--p-m.json](./egg-axolotl--p-m.json) to your panel.

After uploading an egg, you will now be able to install Axolotl-PM server in Pterodactyl/Pelican panel.
